Ce que vous faites en moins

🎵
Tout OSM dans Premiere

L'intégralité du catalogue OSM — musiques originales composées par des musiciens français — accessible directement depuis un panneau ancré dans votre interface de montage. Plus besoin de jongler entre le site et Premiere.

🔍
Trouvez la bonne ambiance

Cherchez par mood, style, instrument, playlist ou sélection de saison. Le moteur de recherche OSM dans votre panneau retrouve le titre qu'il vous faut en quelques secondes, même au milieu d'une session.

🎧
Écoutez sans changer de fenêtre

Préécoutez chaque morceau directement dans le panneau, sans interrompre votre timeline. Quand vous avez trouvé le bon titre, il s'ouvre dans le site pour l'importation dans votre projet.

Prêt en 3 minutes

Installation en 3 étapes

Pas de compte développeur, pas de manipulations techniques. Juste un fichier à double-cliquer.

1
Télécharger le fichier

Cliquez sur le bouton ci-dessous pour télécharger le fichier OSM-Music.ccx sur votre ordinateur. C'est le format d'extension officiel d'Adobe.

↓ Télécharger .ccx
2
Installer l'extension

Fermez Premiere Pro s'il est ouvert. Double-cliquez sur le fichier .ccx téléchargé. Creative Cloud Desktop s'ouvre et vous propose d'installer l'extension — cliquez sur Installer.

3
Ouvrir le panneau

Relancez Premiere Pro et ouvrez un projet. Allez dans le menu Fenêtre → Extensions → OSM Music. Le panneau s'affiche — ancrez-le en glissant son onglet où vous le souhaitez dans l'interface.

Questions fréquentes

Avant de commencer

L'extension fonctionne avec Adobe Premiere Pro 25.6 et toutes les versions plus récentes. Creative Cloud Desktop doit être installé et connecté à votre compte Adobe pour permettre l'installation. Les versions antérieures à 25.6 ne sont pas compatibles avec le format UXP utilisé.
Une connexion internet est nécessaire pour afficher le catalogue. Certaines fonctions du site OSM — comme le téléchargement de fichiers audio ou l'accès aux données compositeurs pour les cue sheets SACEM — peuvent demander un compte OSM. La navigation et l'écoute sont accessibles sans connexion obligatoire.
Non. L'extension est un outil de navigation et d'écoute — elle ne modifie pas les conditions d'utilisation des musiques. Chaque morceau du catalogue OSM reste soumis aux conditions de licence OSM disponibles sur osm-music.fr. L'installation de l'extension ne constitue pas une licence d'utilisation.
Vérifiez ces points dans l'ordre :

1. Version de Premiere : allez dans Aide → À propos de Premiere Pro et vérifiez que vous utilisez la version 25.6 ou une version plus récente.
2. Redémarrage complet : fermez Premiere Pro complètement et relancez-le.
3. Creative Cloud Desktop : ouvrez Creative Cloud Desktop et vérifiez que l'extension OSM Music apparaît bien dans la liste de vos extensions installées.
4. Si le problème persiste, contactez le support : vladimirstreiff@gmail.com
